01 / LOW-POWER SYSTEMS

Embedded E-Ink Dashboard

A low-power ESP32 dashboard integrating real-time calendar, weather, and prayer-time data on a persistent E-Ink display.

Designed the system around power efficiency and memory constraints, integrating REST APIs, OAuth 2.0 authentication, SPI display control, and a custom 1-bit graphics pipeline. The dashboard performs a single data refresh before entering deep sleep.

Embedded E-Ink Dashboard

  • Built a low-power ESP32-based smart dashboard using an e-paper display, aggregating real-time data from Google Calendar and REST APIs.
  • Integrated a 3.97" e-ink display via SPI, managing deep-sleep cycles to optimize power consumption.
  • Engineered a custom graphics rendering pipeline using a 1-bit off-screen framebuffer to compose complex UI layouts.

  • Established one-shot execution logic to trigger deep sleep after each refresh for hardware and battery longevity.

02 / SENSING + VISUALIZATION

LiDAR 3D Mapping System

An embedded spatial-mapping system that reconstructs physical environments from synchronized distance and angular measurements.

Integrated a VL53L1X Time-of-Flight sensor and stepper motor with an MSP432 microcontroller to perform controlled radial scans. Distance and angle data are transmitted over UART and processed in Python/Open3D to generate interactive 3D Cartesian point clouds.

MSP432CI²CUARTToFPythonOpen3D
Full project details

LiDAR 3D Mapping System

  • Developed an embedded system using the MSP432 microcontroller to coordinate sensor data acquisition and motor control.
  • Integrated a VL53L1X Time-of-Flight sensor via I²C for high-speed distance sampling.
  • Processed raw serial data using Python and Open3D to transform polar coordinates into 3D Cartesian point clouds.
  • Implemented polling-based input handling for real-time user control through GPIO push buttons.
  • Controlled a stepper motor through GPIO-driven logic to achieve precise 11.25° angular increments for 32-point radial scans.
  • Established a UART data pipeline at 115200 bps to send raw distance and angle data to a PC for live processing.
  • Produced spatial models consisting of approximately 900 data points through successful system integration.

McMaster SumoBot

  • Integrated ultrasonic and infrared sensors for high-speed opponent tracking and boundary-line avoidance.
  • Optimized a finite state machine to transition between autonomous search, attack, and defend states.

04 / SOFTWARE DESIGN

Snake Game

An object-oriented C++ implementation of Snake built around modular game-state and movement logic.

Reworked procedural game logic into interacting classes using composition and finite-state control. Implemented dynamic growth, coordinate-based collision detection, constrained food generation, score feedback, and explicit memory management validated with Dr. Memory.

C++OOPFSMDynamic MemoryDr. Memory
Full project details

Snake Game

  • Developed a Snake game using object-oriented design, replacing procedural logic with modular interacting classes.
  • Implemented a finite state machine to handle directional input and enforce valid movement transitions.
  • Applied composition by integrating the array list within the Player class to support dynamic growth and state tracking.
  • Designed collision detection for food consumption and self-intersection using coordinate-based comparisons.
  • Implemented constrained random food generation to prevent overlap with the snake body.
  • Added dynamic game-like popups displaying points and length increases when food is collected.
  • Used Dr. Memory to verify heap integrity and eliminate memory leaks through proper allocation and destructor design.
